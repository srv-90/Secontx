Fx Firefox Extension

Follow these steps to load the extension temporarily in Firefox.

  1. Download the extension ZIPSave it somewhere easy to find, such as your Downloads folder.
  2. Open Firefox’s temporary add-on pageEnter about:debugging#/runtime/this-firefox in the address bar.
  3. Choose “This Firefox”Then click Load Temporary Add-on….
  4. Select the extension fileChoose the downloaded ZIP. If Firefox does not accept it, extract it and select manifest.json from the extracted folder.
Temporary installation: Firefox removes the extension when you close or restart the browser, so load it again using the same steps. Firefox keeps unsigned add-ons temporary in its standard version; this mode is intended for testing.
